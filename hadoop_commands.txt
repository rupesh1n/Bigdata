Integration with PySpark
Since your prompt shows you are in a pyspark-env, the next logical step is to ensure Spark can see this Hive Metastore.

In a typical Big Data lab, Spark acts as the "processing engine" while Hive acts as the "catalog" (keeping track of where files are located in HDFS). To test this from your terminal, you would run:


# Exit the docker exec beeline first, then run:
$ pyspark --conf spark.sql.catalogImplementation=hive
Once inside PySpark, run:


>>> spark.sql("SHOW DATABASES").show()
If you see the same databases you saw in Beeline, your Spark-to-Hive integration is perfectly configured.

import sys

    try:
        event = line.split(":")[1].split(",")[0].strip()
        print(f"{event}\t1")
    except:
        continue

#reducer.py
#!/usr/bin/env python3
import sys

current_key = None
current_count = 0

for line in sys.stdin:
    key, value = line.strip().split("\t")
    value = int(value)

    if current_key == key:
        current_count += value
    else:
        if current_key:
            print(f"{current_key}\t{current_count}")
        current_key = key
        current_count = value

if current_key:
    print(f"{current_key}\t{current_count}")
