Explanation:

hadoop jar ...hadoop-streaming-3.2.1.jar: This is the specialized Java library that acts as a "bridge." It allows Hadoop (which is Java-based) to talk to non-Java languages like Python.

 

-input /user/trainee50/logdemo/input/  --> this folder contains BIG log file

-output /user/trainee50/logdemo/output/  --> after exceuting map reduce you will find your output here'

 

You python script is executed here [This is you logic to specify the job]

-mapper "python3 mapper.py" \

-reducer "python3 reducer.py"

 

 

What happens behind the scenes?

Splitting: Hadoop splits your log file into chunks.
Mapping: Your mapper.py runs on each chunk, extracting the "event" name and attaching a 1.
Shuffle & Sort: Hadoop automatically groups all identical "events" together (e.g., all "Login" events are sent to the same place).
Reducing: Your reducer.py receives a list of events and sums up the 1s.
Final Output: The result is saved back to HDFS in your output folder.
